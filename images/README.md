# Images

Drop the finished photos in this folder using these exact filenames. The site
picks them up automatically — no code changes needed. Until a file exists, the
page shows a grey gradient placeholder instead, so nothing breaks.

| Filename | Where it appears | Suggested size |
|---|---|---|
| `hero.jpg` | Full-screen background at the top | 2400 × 1600 |
| `service-house.jpg` | House & Soft Washing | 1600 × 1200 |
| `service-driveway.jpg` | Driveways, Concrete & Pavers | 1600 × 1200 |
| `service-pool.jpg` | Pool Decks & Lanais | 1600 × 1200 |
| `service-fence.jpg` | Decks & Fences | 1600 × 1200 |
| `service-commercial.jpg` | Commercial | 1600 × 1200 |
| `before.jpg` | Left side of the comparison slider | 1920 × 1200 |
| `after.jpg` | Right side of the comparison slider | 1920 × 1200 |
| `favicon.png` | Browser tab icon | 512 × 512 |

## Two rules that matter

1. **`before.jpg` and `after.jpg` must be the exact same scene, framing and
   crop.** The slider wipes between them — if the camera angle shifts even
   slightly, the effect falls apart.

2. **Compress before uploading.** Export as JPEG at ~80% quality and keep each
   file under ~400KB. Use <https://squoosh.app> — it's free and needs no signup.
   Large images are the single most common reason a good-looking site feels slow,
   and slow sites lose quote requests.
